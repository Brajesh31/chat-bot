# Code of Conduct

This project welcomes participation from people with different backgrounds and experience. Everyone taking part should help keep project spaces respectful, useful, and welcoming.

## Expected behavior

- Be considerate and patient.
- Discuss code and ideas without insulting or targeting people.
- Offer constructive feedback and accept good-faith corrections.
- Respect privacy. Do not publish private conversations, personal information, or credentials.
- Give contributors room to learn and ask questions.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, doxxing, repeated unwanted contact, deliberate disruption, sexualized attention without consent, and retaliation for raising concerns are not acceptable.

## Maintainer response

Maintainers may remove harmful content, pause a discussion, or limit participation to keep project spaces safe and productive. Responses should be proportionate and may range from a warning to temporary or permanent exclusion.

## Reporting

Report conduct concerns privately to the maintainer through the contact method on the `@brajesh31` GitHub profile. Include useful context and avoid sharing sensitive information unnecessarily. Security vulnerabilities should be reported privately according to [SECURITY.md](SECURITY.md). If the concern involves the maintainer, use GitHub's platform reporting tools.

This policy applies to repository issues, discussions, pull requests, and other spaces where someone is participating on behalf of the project.
