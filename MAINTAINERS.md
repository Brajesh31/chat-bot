# 🧭 Maintainers

## Current maintainer routing

The repository's current ownership route is recorded in [CODEOWNERS](CODEOWNERS), which assigns the repository paths to [@brajesh31](https://github.com/brajesh31). GitHub's repository permission list remains the source of truth for actual write and administration access.

This document is a maintainer contact and process record. It does not claim that no other contributor has ever participated in the repository.

## Responsibilities

The maintainer on record is responsible for:
- Reviewing proposed changes and their scope.
- Keeping project capabilities accurately represented.
- Maintaining the default branch, release decisions, and repository policies.
- Reviewing dependency and security findings.
- Coordinating private vulnerability reports.
- Keeping documentation, tests, and workflows maintainable.
- Recording important architecture and governance decisions.

## Maintainer changes

When maintainer ownership changes:
1. Confirm the incoming maintainer has the necessary repository permissions.
2. Update CODEOWNERS and this file.
3. Review outstanding Dependabot updates and security findings.
4. Transfer workflow, deployment, and secret-management responsibilities where applicable.
5. Update support and vulnerability-reporting instructions.
6. Record the handover in the decision log.

## Contact and escalation

For ordinary project questions, use repository issues. For security reports, follow [SECURITY.md](SECURITY.md). For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Do not publish private contact details, credentials, or personal information in this file.
