# Support

This is a community project and does not provide a hosted chat service or a guaranteed response time.

## Questions and bug reports

Search existing [issues](https://github.com/Brajesh31/chat-bot/issues) first. In a new issue, describe the prompt, expected response, observed response, browser, and steps to reproduce. Do not include private conversations or personal information.

For setup problems, include Node.js/npm versions and the command that failed, after removing local usernames, paths, and environment values. For a suspected security issue, do not use a public issue; follow [SECURITY.md](SECURITY.md).

## Scope

The current project is a local React interface with fixed response rules. It does not provide accounts, a remote AI assistant, chat storage, or a backend support service. See [CONTRIBUTING.md](CONTRIBUTING.md) to propose improvements.
