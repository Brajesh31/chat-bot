# ♿ Accessibility Guide

Review semantic form controls, accessible names, visible focus, role identification beyond color, contrast, readable text, polite message announcements, narrow viewport reflow, 200% zoom, and reduced motion.

Manual review: navigate with Tab/Shift+Tab; submit using Enter; verify focus order; inspect announcements with assistive technology; test zoom and mobile widths; ensure hover is not essential.

This checklist is not a WCAG conformance claim. Record tested browser and assistive technology for a formal audit.
