# 📄 Content and Asset Provenance

## Scope

This document records the provenance boundary for documentation and visual assets in this repository. It is not a substitute for checking the source code, third-party libraries, fonts, icons, or other external material before redistribution.

## Authored material

New handbook text, templates, diagrams, and original SVG illustrations created as part of this documentation enhancement are authored for this repository and attributed to Brajesh Kumar. This statement does not transfer ownership of pre-existing application code or third-party material.

## Third-party material

The project uses React, React DOM, Vite, ESLint, and related packages listed in package manifests. Their licenses are governed by their respective upstream distributions. The stylesheet references Google Fonts, which have their own family-specific license terms. Review the actual family and version before redistributing font files.

## Repository license

The root LICENSE file intentionally describes a documentation-scope grant rather than asserting an unverified license over all pre-existing source files. Do not replace it with a blanket source-code license unless the repository owner has verified ownership and redistribution rights for all covered code and assets.

## Required review before redistribution

- [ ] Confirm rights to all application source files.
- [ ] Review upstream starter/template provenance.
- [ ] Review dependency licenses and required notices.
- [ ] Review font and icon terms.
- [ ] Check embedded screenshots, logos, and external assets.
- [ ] Keep attribution and notices required by upstream licenses.

## Corrections

If provenance is uncertain, state that uncertainty and investigate it. Do not remove legally required notices merely to make the repository appear uniform.
