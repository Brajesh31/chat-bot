# 📦 Dependencies

Runtime: React and React DOM. Development: Vite, React plugin, ESLint/React plugins, and the test toolchain.

Policy: use npm and preserve `package-lock.json`; prefer maintained dependencies with a clear purpose; review compatibility, ownership, and license; run clean install, lint, tests, and build after upgrades; review Dependabot changes. Do not claim a security audit is clean unless actually run and inspected.
