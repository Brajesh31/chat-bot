# 📦 Dependencies

Runtime packages: React and React DOM. Development packages: Vite, its React plugin, ESLint and React plugins, Vitest, jsdom, and Testing Library.

## Policy
- Use npm and preserve `package-lock.json`.
- Prefer maintained dependencies with a clear purpose.
- Review compatibility, ownership, and license before adoption.
- Run clean install, lint, tests, and build after upgrades.
- Review Dependabot changes.
- Do not claim a vulnerability audit is clean unless run and inspected.
