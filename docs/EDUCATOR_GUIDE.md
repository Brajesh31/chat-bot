# 🎓 Educator Guide

## Suggested 75-minute session
| Time | Activity | Outcome |
|---|---|---|
| 0–10 | Run app | Understand UI |
| 10–25 | Trace components | Identify responsibilities |
| 25–40 | Follow state | Understand React state |
| 40–55 | Inspect rules | See matching limitations |
| 55–65 | Add test | Regression prevention |
| 65–75 | Discuss AI boundary | Separate UI demo from AI service |

Exercises: add a rule and tests, demonstrate a false positive, improve labels/focus, explain why Vite variables cannot store secrets. Use synthetic prompts only.
