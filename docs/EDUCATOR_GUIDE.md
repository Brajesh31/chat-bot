# 🎓 Educator Guide

## Suggested 75-minute session
| Time | Activity | Outcome |
|---|---|---|
| 0–10 | Run app | Understand UI |
| 10–25 | Trace components | Component responsibilities |
| 25–40 | Follow state | React state |
| 40–55 | Inspect rules | Matching limitations |
| 55–65 | Add a test | Regression prevention |
| 65–75 | Discuss AI boundary | Interface vs AI service |

Exercises: add a rule and tests, demonstrate a false positive, improve labels/focus, explain why Vite variables cannot store secrets. Use synthetic prompts only.
