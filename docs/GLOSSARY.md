# 📖 Glossary

| Term | Meaning |
|---|---|
| Bot response | Canned text selected by local rules |
| Chat history | React state array, not persistence |
| Client-only | Browser runs without project backend |
| LLM | Large language model, not integrated here |
| Prompt | Visitor-entered text |
| Rule precedence | First matching branch wins |
| Persistence | Storage beyond page state, not implemented |
| Vite | Development server and bundler |
