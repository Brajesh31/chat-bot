# 📖 Glossary

| Term | Meaning in this repository |
|---|---|
| Bot response | Prewritten text selected by the local response rules |
| Browser-only | Application behavior runs in the visitor's browser without a project backend |
| Canned response | Fixed text prepared in source code |
| Chat history | Array held in React component state, not durable storage |
| Client bundle | HTML, JavaScript, and CSS delivered to the browser |
| Fallback | Local response used when no configured rule matches |
| LLM | Large language model; no LLM is integrated here |
| Model role | Message role label used for bot replies in the UI data structure |
| Phrase matching | Conditional checks against the submitted text |
| Persistence | Storage beyond temporary component state; not implemented |
| Precedence | The first matching conditional branch takes priority |
| Prompt | Text entered by a visitor |
| Regression test | Test that protects previously expected behavior |
| React state | Component-managed values that drive rendering |
| Vite | Development server and build tool used by this project |
| VITE_ variable | Client-exposed Vite environment variable; never a place for secrets |

Use these terms consistently in the README, issue reports, lessons, and technical documentation. Avoid describing the local matcher as a reasoning engine or AI inference system.
