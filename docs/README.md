# 📚 Documentation Hub

This handbook documents the current browser-only React application. It separates implemented behavior from proposed capabilities and links to project, architecture, setup, UX, quality, operations, security, privacy, and governance guides.

> **Important:** ChatBuddy uses local phrase matching and prewritten responses. It does not call an LLM, server API, database, or persistent transcript store.
