# 🙏 Acknowledgements

ChatBuddy is built on open-source tools and documentation that make a small frontend learning project possible.

## Core ecosystem

- **React** provides the component model and state-driven rendering used by the interface.
- **React DOM** mounts the application into the browser document.
- **Vite** provides local development and the static production build.
- **Node.js** provides the runtime for development tooling and the built-in test runner.
- **ESLint** provides configurable static analysis.
- **GitHub Actions** provides repository automation, CI, and static analysis workflows.

## Learning and maintenance

The project benefits from the maintainers and contributors of these tools, their published documentation, issue discussions, release notes, and security advisories.
