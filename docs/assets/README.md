## Asset rules

- Each SVG must include a title and description.
- Keep text readable at normal document scale.
- Use diagrams to explain implemented behavior, not to imply missing features.
- Do not label an illustration as a real screenshot.
- Update the corresponding documentation when source behavior changes.
- Add useful alternative text wherever an image is embedded.

## Provenance

These illustrations are authored for this repository. Third-party logos, trademarks, and font files are not embedded in these diagrams.
