## Asset rules

- Every SVG includes a title and description.
- Keep text readable at normal document scale.
- Use diagrams to explain implemented behavior, not imply missing features.
- Do not label an illustration as a real screenshot.
- Update the corresponding documentation when source behavior changes.
- Add useful alternative text wherever an image is embedded.
- Prefer original, locally stored SVGs over third-party stock artwork.

## Screenshot status

No real browser screenshots are included in this directory. Capture screenshots from an actual verified browser build before describing them as screenshots. Do not turn an illustrative wireframe into a fake screenshot.

These logo and illustration assets are authored for this repository. Third-party logos, trademarks, and font files are not embedded in these diagrams.
