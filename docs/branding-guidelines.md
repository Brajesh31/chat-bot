# 🎨 Branding Guidelines

## Project name and positioning

Use **ChatBuddy** for the in-interface assistant label and **Chat Bot** as the repository/project title where appropriate. Describe it as a local scripted chat UI demonstration.

## Visual identity

The current interface uses purple and lavender surfaces, rounded chat bubbles, a bot icon, and Inter-based typography. Original SVG illustrations in docs/assets/ are explanatory visuals and should use the same general visual language.

## Voice and tone

- Friendly, clear, and direct.
- Honest about the scripted response model.
- Avoid claims of intelligence, live information, human support, or generative AI.
- Explain the purpose of controls in plain language.

## Logo and imagery

The current bot icon is an application graphic. New project logo and banner assets should be original and should not imitate third-party trademarks. Wireframes must be labelled as illustrations, not real screenshots.

## Badge policy

Use badges for actual technologies and checks. Do not add passing quality, security, coverage, deployment, or release badges unless the underlying evidence exists and is current.
