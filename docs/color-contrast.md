# 🎨 Color Contrast Review

## Current palette

The main UI uses a purple header and visitor bubble, lavender assistant bubble, white card, and dark purple focus outline. The color system documents current CSS values.

## Required measurements

Measure text and controls in all meaningful states:
- White header text on purple.
- White visitor text on purple.
- Dark text on assistant lavender.
- Helper/disclaimer text on white.
- Input placeholder and entered text.
- Focus outline against adjacent backgrounds.
- Hover state of header and send controls.

## Review criteria

Use WCAG 2.2 AA contrast criteria where applicable. Normal text, large text, graphical components, and focus indicators have different evaluation requirements. Do not assume that colors are compliant because they appear readable on one display.

## Evidence record

Record foreground/background values, computed opacity, font size/weight, measured ratio, tool, page state, and result. No formal contrast measurement is claimed by this file.
