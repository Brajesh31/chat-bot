## Contrast and state

Measure text and control contrast with a contrast analyzer. Check normal and hover states, focus outlines, disabled controls if introduced, and long-message surfaces. Do not infer WCAG conformance from the color values alone.

## Color usage

Use purple as the primary action and identity color. Use neutral surfaces to separate messages. Keep the visitor and assistant message distinction understandable through alignment and labels, not color alone.

## Change validation

When changing the palette, review all affected CSS selectors, visual assets, README illustrations, and accessibility notes. Update DESIGN_TOKENS.md and manual browser evidence.
