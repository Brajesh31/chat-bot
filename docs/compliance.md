# 📜 Compliance Status

## Current status

The repository does not claim certification, regulatory compliance, SOC 2, ISO 27001, GDPR compliance, or formal WCAG conformance. It is a small frontend demonstration with no backend or persistent transcript store.

## Practices currently documented

- Dependency and static analysis workflows.
- Security reporting guidance.
- Privacy boundary documentation.
- Accessible UI implementation guidance.
- Contributor and release processes.
- License and third-party provenance cautions.

## Compliance assessment requirements

Any formal claim requires a defined scope, applicable criteria, evidence, control owner, independent review where appropriate, and current assessment results. A checklist or code scanner alone does not establish compliance.

## Future changes

Remote storage, analytics, authentication, payments, or model-provider processing may change legal and compliance obligations. Update the data inventory and obtain qualified review before making compliance claims.
