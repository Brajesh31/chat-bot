# Sample Prompts

| Category | Prompt | Behavior |
|---|---|---|
| Greeting | `hello` | Greeting |
| Morning | `good morning` | Morning greeting |
| Joke | `tell me a joke` | Random joke |
| Fact | `tell me a fact` | Random fact |
| Help | `help` | Help response |
| Weather | `weather` | Static statement, not forecast |
| Unknown | `explain quantum computing` | Fallback |

Examples do not imply general language understanding.
