# 🔏 Privacy Notes

The form passes text to local React logic. Messages remain in component state while the page is mounted. There is no transcript database, account, or chat API.

HTML/CSS reference Google Fonts, so browsers may contact that host. This is separate from chat processing.

Before model or analytics integration, disclose fields, recipients, purpose, consent, retention, deletion, and provider processing. Minimize prompt collection, keep credentials server-side, and define failure behavior. This is not a legal notice or compliance certification.
