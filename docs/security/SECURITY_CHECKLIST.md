# ✅ Security Checklist

## Repository/build
- [ ] No secrets or local environment committed.
- [ ] Workflow permissions least-privilege.
- [ ] Third-party Actions reviewed/pinned where appropriate.
- [ ] Dependency alerts reviewed.
- [ ] Build output contains no credentials.

## Browser
- [ ] User text rendered safely.
- [ ] External resources documented.
- [ ] Sensitive prompts not logged.
- [ ] Input size bounded where appropriate.

## Before remote AI
- [ ] Server-side provider secrets.
- [ ] Consent and privacy disclosure.
- [ ] Validation, rate limits, abuse controls.
- [ ] Timeout and provider error handling.
- [ ] Retention, deletion, access controls.
- [ ] Untrusted prompt/content review.

Record reviewer, date, and commit for completed checks.
