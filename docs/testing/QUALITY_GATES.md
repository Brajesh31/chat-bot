# 🚦 Quality Gates

- [ ] Focused scope and acceptance criteria.
- [ ] ESLint passes.
- [ ] Unit/component tests pass.
- [ ] Production build succeeds.
- [ ] Keyboard/narrow viewport checks for UI changes.
- [ ] Docs/examples updated.
- [ ] No secrets or real transcripts added.
- [ ] Dependency and asset provenance reviewed.

CI is automated evidence only. Manual accessibility and live deployment checks must be reported separately.
