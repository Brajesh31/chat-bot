# 🚦 Quality Gates

- [ ] Focused scope and acceptance criteria.
- [ ] ESLint passes.
- [ ] All automated tests pass.
- [ ] `npm audit --audit-level=high` reports no high-severity advisories.
- [ ] Production build succeeds.
- [ ] Keyboard and narrow-viewport checks completed for UI changes.
- [ ] Docs and examples updated.
- [ ] No secrets or real transcripts added.
- [ ] Dependency and asset provenance reviewed.

CI provides automated evidence for lint, tests, high-severity dependency audit, and build. Manual accessibility and live deployment checks must be reported separately.
