# 🔤 Typography

## Current font stack

The main stylesheet requests Inter through Google Fonts and includes a sans-serif fallback. The page may make separate requests to Google's font infrastructure. The browser fallback should remain readable when external fonts are blocked or unavailable.

## Usage guidance

- Use the project heading for the product name, not decorative text.
- Keep chat content readable at normal zoom.
- Preserve line-height and wrapping for long messages.
- Avoid excessively small text for disclosures and helper copy.
- Ensure controls remain readable on narrow viewports.
- Do not rely on font weight alone to communicate status.

## Licensing and privacy

Before self-hosting font files, verify the license for the specific font files and weights. Document any new third-party download. Do not claim that the current external font request is self-hosted.

## Validation

Check at 100% and 200% zoom, with Google Fonts blocked, and with system font fallback. Record actual findings instead of claiming universal rendering consistency.
